# Измерение скорости скачивания

Консольный скрипт на Python 3.10+ без сторонних зависимостей.

## Запуск

Скачайте репозиторий или клонируйте его и перейдите в папку проекта:

```sh
git clone https://github.com/Gelikc/internet-speed-test.git
cd internet-speed-test
python speed_test.py "https://example.com/large-image.jpg"
```

Замените пример адресом доступного большого файла. В Windows вместо `python`
можно использовать `py`, в Linux/macOS — `python3`.

Дополнительные параметры:

```sh
python speed_test.py "https://example.com/large-image.jpg" --timeout 60
python speed_test.py --help
```

`--timeout` — время ожидания отдельной сетевой операции в секундах
(по умолчанию 30), а не ограничение длительности всего скачивания.

## Как считается результат

Скрипт выполняет ровно **10 последовательных GET-запросов** к указанному
HTTP/HTTPS-адресу. Каждый ответ полностью считывается блоками по 64 КиБ,
поэтому файл целиком не хранится в памяти и не сохраняется на диск.
Перенаправления обрабатываются стандартной библиотекой; они могут добавлять
HTTP-обмены внутри одного из десяти скачиваний.

Для каждого запроса измеряется время от начала открытия соединения до
полного чтения и закрытия ответа, включая установление соединения,
TLS и ожидание сервера. Выводятся:

- среднее время: сумма времён / 10, в секундах;
- общий объём фактически прочитанных тел ответов, в байтах и МБ;
- скорость: общий объём × 8 / сумма времён / 1 000 000, в **Мбит/с**.

1 МБ = 1 000 000 байт; 1 Мбит/с = 1 000 000 бит в секунду.
HTTP-заголовки и служебный сетевой трафик в объём не входят.
Время печати в консоль не входит в измерение.

Скрипт просит сервер отключить сжатие и повторную выдачу из кеша.
Сервер или прокси могут игнорировать эти заголовки. Результат показывает
скорость загрузки с конкретного сервера, которая зависит также от его
производительности, задержки и размера файла. Это не гарантированная
пропускная способность интернет-канала.

При сетевой ошибке, HTTP-ошибке или неполном ответе измерение прекращается
с кодом 1 и сообщением в stderr; итог для десяти запросов не выводится.
Некорректные аргументы дают код 2, прерывание Ctrl+C — 130.

## Проверка

Тесты используют локальный HTTP-сервер и не требуют интернета:

```sh
python -m unittest discover -s tests -v
```
